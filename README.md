# 班級拍賣點數小幫手

同學用 Google 試算表上的「目前累積點數」當籌碼，在手機上競標老師準備的物品。

- **首頁（不用登入）**：任何人都看得到拍賣中和即將開始的物品、目前最高價和剩餘時間，但看不到出價者座號。
- **學生**：用座號和密碼登入，看物品照片、目前最高價、剩餘時間，然後出價。
- **老師**：上傳物品照片，設定底價和拍賣時間；可以提早結標，查看得標統計，產生學生密碼。

## 拍賣規則

- 第一次出價不能低於底價，之後每次至少要比目前最高價多 1 點。
- **可用點數 = 試算表點數 − 自己目前領先的出價 − 已得標但老師還沒按「已扣點」的金額**。
  所以同時競標好幾件物品時，總額不會超過自己的點數。
- 出價被別人超過後，那筆點數就會還回來。
- 時間一到自動結標；出價最高的人得標（同分時先出價的人得標）。
- 網站只**讀取**試算表，不會修改它。得標後，老師照「得標統計」頁的「待扣點」表格，
  到試算表新增一列扣點，扣完再按「標記已扣點」。

## 在教室電腦執行（建議用法）

網站跑在老師的電腦上，同學的手機連**同一個 Wi-Fi** 打開網址出價。不需要 Zeabur。

### 啟動：點兩下「啟動拍賣網站.bat」

- **第一次執行**：會自動建立 Python 環境、安裝套件（需要網路，大約 1 分鐘）、建立設定檔 `.env`，
  並在視窗裡顯示**老師密碼**（之後可以用記事本打開 `.env` 修改 `TEACHER_PASSWORD`）。
- 啟動後，視窗會顯示兩個網址，瀏覽器也會自動打開：
  - 老師（這台電腦）：`http://127.0.0.1:5000`
  - 同學手機：`http://192.168.x.x:5000`（每台電腦不一樣，請看視窗上顯示的）
- **要關閉網站**：直接關掉那個黑色視窗。
- 第一次啟動時，如果 Windows 防火牆跳出視窗，請按「允許存取」，手機才連得進來。

### 複製到別台電腦

把整個 `python1010` 資料夾複製過去（隨身碟、雲端硬碟都可以），在新電腦上點兩下「啟動拍賣網站.bat」就好。

- 新電腦要先裝 **Python 3.11 以上**（到 <https://www.python.org> 下載，安裝時勾選 **Add python.exe to PATH**）。
- `.venv` 資料夾可以不用複製（它很大）；就算複製了，啟動檔也會發現它不能用並自動重建。
- `auction.db` 是所有拍賣資料（物品、出價、學生密碼）。**複製它就會把資料一起帶過去**；
  不複製就是全新的空白網站。複製前請先關掉網站。
- `.env` 裡有老師密碼；不複製的話，新電腦會產生新的老師密碼。
- 新電腦第一次執行時需要網路來安裝套件；之後讀 Google 試算表點數也需要網路。

### 手機連不進來時

1. 確認手機和電腦連的是**同一個 Wi-Fi**。
2. 檢查 Windows 防火牆：「設定 → 隱私權與安全性 → Windows 安全性 → 防火牆與網路保護 →
   允許應用程式通過防火牆」，確認 Python 有勾選「私人」網路。
3. 學校 Wi-Fi 有時會禁止裝置互連。這時可以用**老師手機開熱點**，電腦和同學手機都連這個熱點。

### 進階：自己用指令啟動

```powershell
.venv\Scripts\python serve.py      # 和點兩下 .bat 一樣
.venv\Scripts\python app.py        # 開發用：改程式存檔後會自動重新載入
```

### 試用流程

1. 在登入頁點「老師登入」，輸入 `.env` 裡的老師密碼。
2. 到「學生密碼」頁，按「全部座號產生新密碼」，記下其中一個座號的密碼。
3. 回到「物品」頁，按「新增物品」：上傳照片、填底價，開始時間設成現在，結束時間設成稍晚。
4. 開一個**無痕視窗**（`Ctrl + Shift + N`），用剛剛的座號和密碼以學生身分登入，然後出價。
5. 回到老師視窗，可以看到出價紀錄，也可以按「提早結標」，再到「得標統計」查看結果。

本機的資料存在 `auction.db` 這個檔案裡。想清空重來，就關掉網站、刪除這個檔案，再重新啟動。

### 執行自動化測試

```powershell
.venv\Scripts\python -m pytest
```

最後出現 `22 passed` 就代表全部功能都正常。測試用的是假資料，不會動到你的 `auction.db`，也不會連到 Google 試算表。

## （選用）部署到 Zeabur

如果之後想讓同學在家也能用手機出價，可以部署到雲端。

### 1. 把程式碼放上 GitHub

先在 GitHub 網站建立一個新的 repository（建議設成 **Private**），然後執行：

```powershell
git init
git add .
git commit -m "班級拍賣網站"
git branch -M main
git remote add origin https://github.com/你的帳號/你的repo名稱.git
git push -u origin main
```

`.env`（裡面有密碼）和 `auction.db` 不會被上傳，因為已經寫在 `.gitignore` 裡了。

### 2. 在 Zeabur 建立服務

1. 登入 [Zeabur](https://zeabur.com)，建立一個新專案（地區建議選離台灣近的，例如 Tokyo 或 Taiwan）。
2. 按「新增服務」→「資料庫」→ **PostgreSQL**。
3. 再按「新增服務」→ **GitHub**，選你的 repository。Zeabur 看到 `Dockerfile` 就會自動建立網站。
4. 點進網站服務 →「環境變數」，新增：

   | 名稱 | 值 |
   |---|---|
   | `TEACHER_PASSWORD` | 你的老師密碼 |
   | `SECRET_KEY` | 一長串亂碼 |
   | `SHEET_ID` | `13fp6-NU20QT75KteyX7KI2STr9z_o34ew9JnwevOaWE` |
   | `DATABASE_URL` | PostgreSQL 的連線字串（見下方說明） |

   **連線字串**：點進 PostgreSQL 服務，在「連線」（Connection / Instructions）頁籤找到以
   `postgresql://` 開頭的那一串，整串複製貼上。

5. 到網站服務的「網路」（Networking）頁籤產生一個網址，例如 `xxx.zeabur.app`，這就是要給同學的網址。

以後只要改完程式、`git push` 到 GitHub，Zeabur 就會自動重新部署。拍賣資料存在 PostgreSQL 裡，重新部署也不會消失。

> Zeabur 的方案和計費方式會變動，PostgreSQL 也會用到資源。費用請以 Zeabur 官網為準。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `app.py` | 網站主程式：所有網址和畫面的處理 |
| `models.py` | 資料表：學生、物品、出價紀錄 |
| `auction.py` | 拍賣規則：可用點數計算、出價檢查 |
| `sheet.py` | 讀取 Google 試算表的「目前累積點數」 |
| `templates/` | 網頁畫面 |
| `static/` | 樣式（`style.css`）和自動更新（`app.js`） |
| `tests/` | 自動化測試 |
| `啟動拍賣網站.bat` | 點兩下啟動網站（教室電腦用） |
| `serve.py` | 啟動網站並顯示同學要用的網址 |
| `requirements-local.txt` | 教室電腦需要的套件 |
| `Dockerfile` | 告訴 Zeabur 怎麼啟動網站 |
| `.env.example` | 設定範例 |

## 常見問題

- **學生頁顯示「暫時讀不到點數」**：確認試算表的分享設定是「知道連結的任何人都能檢視」。
  如果試算表有多個分頁，在 `SHEET_GID` 填入「點數」那個分頁網址最後 `gid=` 後面的數字。
- **試算表改了點數，網站沒有馬上更新**：網站每 60 秒才重新讀一次試算表，等一分鐘就好。
- **同學忘記密碼**：老師到「學生密碼」頁，按該座號的按鈕重設。
- **密碼打錯 5 次**：該座號會被鎖住 5 分鐘。
- **24～30 號沒有點數**：這些座號在試算表上是 0 點，所以不能出價。
